# CareVolution Healthcare Inc. — Website

Landing page for CareVolution Healthcare Inc., Belleville, Ontario.

*Driven by Values. United by Care. Committed to Excellence.*

## Structure

- `index.html` — page markup and content
- `styles.css` — brand styles (Sanctuary Blue, Maple Vital Red, Growth Sage, Warm Beige; Bespoke Serif + Manrope)
- `main.js` — mobile nav, service tabs, scroll reveals
- `assets/` — wordmark and icon SVGs

No build step: open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Cloudflare Pages, Netlify).

## Before launch

- The contact form posts to FormSubmit; approve the one-time activation email sent to info@carevolution.ca after the first submission.
- Photos are free-licence Unsplash images loaded from Unsplash's CDN; replace with downloaded copies or approved CareVolution photography.
- Add the Privacy Policy, Terms of Use and Accessibility pages linked in the footer.
